# Установка StealthNode

## 0. Что понадобится

| Что | Требования |
|---|---|
| VPS | за рубежом, **Ubuntu 24.04 LTS**, от 1 ГБ RAM (лучше 2), 10+ ГБ диска, публичный IPv4 |
| Домен | A-запись → IP VPS; по умолчанию `vpn.shprv.ru` (можно любой) |
| Доступ | SSH под root или пользователем с sudo |
| Время | 5–15 минут |

**Выбор VPS.** С июня 2026 ТСПУ строже относится к «подозрительным» подсетям (крупные
облака и хостинги, массово используемые под VPN). Лучше небольшой европейский провайдер;
проверьте, что IP не в блок-листах (`https://check-host.net` → ping из России).

## 1. DNS

В панели регистратора создайте запись:

```
vpn.shprv.ru.   300   IN   A   <IP вашего VPS>
```

TTL 300 позволит быстро переехать на другой IP. Проверка (с любого компьютера):
`dig +short vpn.shprv.ru` → должен показать IP VPS. Если запись ещё не разошлась —
установку можно запускать: Caddy получит сертификат сам, когда DNS заработает.

## 2. SSH-ключ (рекомендуется)

На своём компьютере: `ssh-copy-id root@<IP>` (или добавьте ключ в панели хостинга). Проверьте,
что входите без пароля — только после этого используйте `--ssh-keys-only`.

## 3. Установка

```bash
ssh root@<IP>
apt-get update && apt-get install -y git
git clone https://github.com/Rimlin-UNC/home_VPN.git
cd home_VPN
sudo bash stealthnode/install.sh --domain vpn.shprv.ru --email you@example.com \
    --user mama:50:2 --user papa:50:2
```

`--user имя:ГБ:IP` — пользователь с лимитом ГБ в месяц (0 — без лимита) и числом одновременных
IP. Владелец `owner` создаётся всегда, без лимитов.

### Все параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--domain` | `vpn.shprv.ru` | домен сервера |
| `--email` | — | почта для Let's Encrypt (предупреждения об истечении) |
| `--sni` | `max.ru` | SNI/цель REALITY ([как выбрать](#выбор-sni)) |
| `--target` | `<sni>:443` | адрес цели REALITY, если отличается |
| `--user ИМЯ[:ГБ[:IP]]` | — | пользователь (можно несколько) |
| `--limit-gb`, `--ip-limit` | 50, 2 | значения по умолчанию для новых пользователей |
| `--ssh-keys-only` | выкл. | вход по SSH только по ключам |
| `--ssh-port N` | 22 | дополнительный порт SSH (22 остаётся открыт) |
| `--ssh-close-22` | — | закрыть 22 после проверки входа по новому порту |
| `--admin-ip IP` | — | никогда не банить этот IP в fail2ban |
| `--panel-port N` | случайный 20000–29999 | внешний порт панели и подписок |
| `--hy2-port N` | 443 | UDP-порт Hysteria2 |
| `--tg-token`, `--tg-chat` | — | включить Telegram-бот 3x-ui |
| `--restore АРХИВ` | — | перенос с другого сервера |
| `--no-auto-reboot` | — | не перезагружаться после обновления ядра (по умолчанию 01:30 UTC) |
| `--skip-upgrade` | — | не делать `apt upgrade` |
| `--strict-dns` | — | остановиться, если A-запись не указывает на сервер |
| `--tls internal` | — | без Let's Encrypt (только для тестов) |

Повторный запуск `install.sh` **безопасен**: ключи, пароли, порты и пользователи сохраняются;
исправляется только то, что отличается от нужного. Так же обновляется StealthNode:
`cd home_VPN && git pull && sudo bash stealthnode/install.sh`.

## 4. После установки

1. `sudo cat /root/stealthnode-credentials.txt` — адрес панели, логин, пароль, подписка владельца.
2. `sudo stealthnode doctor --e2e` — все проверки должны быть `[ OK ]`.
3. Откройте панель, выберите **Русский** на странице входа, в настройках включите
   **двухфакторную аутентификацию**.
4. Раздайте профили: `/opt/stealthnode/users/<имя>/links.txt` и `qr-subscription.png`
   (или `sudo stealthnode user show mama --qr`). Как импортировать — [CLIENTS.md](CLIENTS.md).

### Нестандартный порт SSH — безопасно

```bash
sudo bash stealthnode/install.sh --ssh-port 2222 --ssh-keys-only   # 22 и 2222 открыты
ssh -p 2222 root@<IP>                                               # проверить в НОВОМ окне
sudo bash stealthnode/install.sh --ssh-close-22                     # закрыть 22
```

## Выбор SNI

REALITY маскирует трафик под TLS-сайт (цель). Требования к цели: TLS 1.3, HTTP/2, X25519
(лучше X25519MLKEM768), валидный сертификат, доступность с VPS, малая задержка.

```bash
sudo stealthnode sni-check                      # кандидаты по умолчанию
sudo stealthnode sni-check www.example.pl ya.ru # свои кандидаты
sudo stealthnode sni-set ya.ru                  # сменить (пользователям — обновить подписку)
```

По ТЗ по умолчанию `max.ru`. Для зарубежного сервера российский SNI — заметное несоответствие;
лучший вариант — сайт из той же сети (AS), что и VPS (см. [TZ-REVIEW.md](TZ-REVIEW.md), п. 2.8).
Никогда не используйте сайты Google/Microsoft/Apple/Cloudflare и цели за CDN.

## Переезд на новый VPS (например, IP заблокирован)

```bash
# на старом сервере (или возьмите последний ежедневный архив)
sudo stealthnode backup
scp root@OLD:/opt/stealthnode/backups/stealthnode-*.tar.gz .
# на новом сервере
scp stealthnode-*.tar.gz root@NEW:/root/
sudo bash stealthnode/install.sh --restore /root/stealthnode-ДАТА.tar.gz
```

Затем смените A-запись домена на новый IP. Ключи, пароли, пользователи и ссылки — прежние,
клиенты переподключатся сами (адрес в ссылках — домен).

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `doctor`: сертификат панели не прошёл проверку | A-запись не указывает на сервер или закрыт 80/tcp у хостинга. Проверьте `dig +short ДОМЕН`; журнал `journalctl -u caddy`. |
| Панель не открывается | Порт панели — в credentials (`:2xxxx`); путь обязателен. Проверьте фаервол хостинга (не только UFW). |
| `порт 443/tcp занят процессом …` | На сервере уже есть веб-сервер/VPN: `systemctl disable --now nginx` (или другой) и повторите. |
| Клиент не подключается, остальное `OK` | Клиент не на Xray-core ≥ 26.3.23 или sing-box — см. [CLIENTS.md](CLIENTS.md). |
| Hysteria2 не подключается | Оператор режет UDP — используйте профили VLESS. |
| Установка прервалась | Исправьте причину из сообщения и запустите `install.sh` снова; журнал — `/var/log/stealthnode/`. |

Удаление: `sudo bash stealthnode/uninstall.sh` (панель и бэкапы остаются; `--purge-panel`,
`--purge-all` — полное удаление).
