# ТЗ v2 «StealthNode» — требования заказчика

Структурированное изложение технического задания из сообщения заказчика от 14.10.2026.
Разбор пробелов и принятые решения — в [TZ-REVIEW.md](TZ-REVIEW.md); соответствие требований
реализации — в таблице в конце документа.

## 1. Цель

Личный VPN на одном чистом VPS за рубежом (Ubuntu 24.04 LTS) для владельца и родственников
(до 10 пользователей) с лимитами трафика, устойчивый к DPI/ТСПУ в России (2026).
Домен: `vpn.shprv.ru` (A-запись на IP VPS).

## 2. Протоколы

| Профиль | Параметры |
|---|---|
| Основной: VLESS + XHTTP + REALITY | порт 443/tcp; `mode=stream-one` явно на сервере и в ссылке; без flow; отпечаток `fp=firefox`; SNI российского сервиса (`max.ru` или `yandex.ru`) |
| iOS: VLESS + TCP + REALITY + Vision | порт 8443/tcp; `flow=xtls-rprx-vision`; те же ключи REALITY и shortId |
| Резерв: Hysteria2 + Salamander | UDP (например, 443/udp); обфускация Salamander |

Запрещено: отпечаток `chrome`, CDN перед REALITY, SNI Google/Microsoft.

## 3. Панель и пользователи

- Панель **3X-UI** (предпочтительно), доступ по **HTTPS через Caddy**, интерфейс на русском.
- Владелец — без лимита; родственники — например, **50 ГБ/мес**; лимит одновременных IP **1–2**.
- Одна подписка (общий subId) на все профили пользователя; QR-коды для импорта.
- Telegram-бот (низкий приоритет).

## 4. Сервер и безопасность

- dnscrypt-proxy (шифрование DNS-запросов).
- UFW: 22, 80, 443, 8443, UDP Hysteria2, порт панели.
- fail2ban: SSH — 3 попытки за 10 минут → бан на 24 часа; защита панели от перебора пароля.
- BBR и усиление sysctl; автоматические обновления безопасности (unattended-upgrades).
- SSH: вход только по ключам, root — по ключу, нестандартный порт (опционально).

## 5. Файлы

```
/opt/stealthnode/
├── xray/config.json
├── xray/share/admin-links.txt
├── hysteria/config.yaml, server.crt, server.key
├── caddy/Caddyfile
├── .env            (права 600)
└── users/          (опционально, профили пользователей)
/root/stealthnode-credentials.txt   (учётные данные)
```

## 6. Порядок установки (по ТЗ)

1. `apt update && apt upgrade`, базовые пакеты.
2. Xray (служба), 3. Hysteria2, 4. 3X-UI, 5. Caddy, 6. dnscrypt-proxy, 7. UFW + fail2ban,
8. BBR/sysctl, 9. пользователи и ссылки, 10. проверка.

## 7. Тесты (раздел 8 ТЗ)

Службы запущены; порты слушаются; панель открывается по HTTPS (`curl -k https://vpn.shprv.ru`);
REALITY-рукопожатие проходит; лимиты отключают пользователя; fail2ban банит.

## 8. Критерии приёмки

- Работает с мобильного интернета в РФ; клиенты iOS, Android, Windows.
- Панель доступна по HTTPS; при превышении лимита пользователь отключается.
- Скорость не ниже 20 Мбит/с; файлы с секретами — права 600.

## 9. Соответствие реализации

| Требование | Реализация | Отклонение |
|---|---|---|
| VLESS+XHTTP+REALITY 443, stream-one, без flow, firefox | ✅ | — |
| VLESS+TCP+REALITY+Vision 8443, те же ключи | ✅ | — |
| Hysteria2+Salamander UDP | ✅ 443/udp | внутри Xray (3x-ui), а не отдельным бинарником — ради лимитов и подписки; `hysteria/config.yaml` не нужен |
| 3X-UI + HTTPS через Caddy | ✅ | Caddy на отдельном порту (443 занят Xray) |
| Русский интерфейс | ✅ | язык выбирается на странице входа 3x-ui |
| Лимиты 50 ГБ/мес, 1–2 IP, владелец без лимита | ✅ | по умолчанию 2 IP (CGNAT) |
| Одна подписка, QR | ✅ | — |
| Telegram-бот | ✅ встроенный бот 3x-ui | — |
| dnscrypt-proxy | ✅ | используется Xray; системный резолвер не меняется |
| UFW | ✅ | сырые порты панели/подписки не открываются |
| fail2ban SSH 3/10м/24ч + панель | ✅ | + recidive, + лимит IP 3x-ui |
| BBR, sysctl, unattended-upgrades | ✅ | — |
| SSH ключи / порт (опц.) | ✅ `--ssh-keys-only`, `--ssh-port` | безопасный переход через `--ssh-close-22` |
| Файлы в /opt/stealthnode, .env 600, credentials | ✅ | `xray/config.json` — экспорт (источник правды — БД 3x-ui) |
| Отдельная служба Xray | ❌ намеренно | ядро Xray запускает 3x-ui |
| Тесты раздела 8 | ✅ `stealthnode doctor --e2e` | исправлены (см. TESTING.md) |
| SNI max.ru/yandex.ru | ✅ по умолчанию max.ru | риск описан, есть `sni-check`/`sni-set` |
