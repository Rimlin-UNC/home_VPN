# Безопасность StealthNode

## Модель угроз

| Угроза | Мера |
|---|---|
| DPI/ТСПУ распознаёт VPN | REALITY: без ключа сервер неотличим от настоящего сайта-цели (отдаёт его сертификат); XHTTP stream-one; fp=firefox; Hysteria2 обфусцирован Salamander (без пароля пакеты — случайный шум) |
| Активное зондирование сервера | неверный shortId/ключ → соединение уходит к цели (проверено тестом); панель не на стандартном порту, корень сайта отвечает 404, путь панели случайный |
| Перехват/подмена (MITM) | REALITY — аутентификация по ключу; Hysteria2 — сертификат Let's Encrypt или pinSHA256, **без `insecure`**; панель только по HTTPS |
| Подбор паролей | SSH: fail2ban 3/10 мин → 24 ч, `ufw limit`, опционально только ключи; панель: случайный путь, встроенный лимит 3x-ui (5 ошибок/5 мин → 15 мин) + fail2ban (10 настоящих ошибок/час → бан 1 ч на порту панели; отказы лимита не считаются, чтобы не банить владельца с верным паролем) + recidive 7 дней; пароль панели 24 символа (свой — от 8, лучше от 12) |
| Утечка секретов | `.env`, учётные данные, ключи, профили — права 600, каталоги 700, владелец root; секреты не пишутся в журнал установки |
| Злоупотребление доступом родственником | квоты трафика и лимит IP; Xray 26 не пускает клиентов в приватные сети сервера |
| Уязвимости ПО | автообновления безопасности Ubuntu; закреплённые проверенные версии 3x-ui/Xray; панель за Caddy и только на 127.0.0.1; служба 3x-ui с sandbox systemd |
| Блокировка IP сервера | ссылки на домен; ежедневные бэкапы; переезд `--restore` без смены ссылок |
| Компрометация цепочки поставки | установщик 3x-ui закреплён по тегу и SHA256; архив релиза проверяется по `.sha256`; Caddy — подписанный APT-репозиторий |

## Что видно провайдеру VPS и кому-либо ещё

- Провайдер VPS видит объём трафика и адреса назначения (как любой провайдер). Журнал подключений
  Xray (`access.log`) **отключён**: на сервере не хранится, кто и куда ходил.
- DNS-запросы Xray идут через dnscrypt-proxy (шифрованно) к резолверам без логов.
- Домен попадает в публичные журналы сертификатов (CT) — так работает любой HTTPS. Поэтому слово
  «vpn» в имени домена нежелательно (см. TZ-REVIEW, п. 3.1).

## Рекомендации владельцу

1. Включите **2FA** в панели 3X-UI (Настройки → Безопасность).
2. Используйте SSH-ключи и `--ssh-keys-only`; по желанию — нестандартный порт.
3. Храните копию `/root/stealthnode-credentials.txt` и бэкапы в менеджере паролей/зашифрованном
   хранилище, не в мессенджерах.
4. Не публикуйте ссылки и QR — это ключи доступа. Скомпрометированного пользователя удалите
   (`stealthnode user del`) и создайте заново (новые UUID/пароль/subId).
5. Периодически: `stealthnode doctor --e2e`, `stealthnode unban` (текущие баны).
6. Свой постоянный IP добавьте в исключения fail2ban: `install.sh --admin-ip <IP>`. Забыли пароль
   панели — `stealthnode panel-password` (по SSH), а не переустановка.

## Сетевые порты

| Порт | Открыт наружу | Служба |
|---|---|---|
| 22/tcp (или свой) | да, `limit` | SSH |
| 80/tcp | да | Caddy: только проверка Let's Encrypt (HTTP-01), без редиректа |
| 443/tcp | да | Xray: VLESS + XHTTP + REALITY |
| 8443/tcp | да | Xray: VLESS + TCP + REALITY + Vision |
| 443/udp | да | Xray: Hysteria2 + Salamander |
| 20000–29999/tcp (один) | да | Caddy: HTTPS панели и подписки |
| 30000–39999/tcp (один) | **нет** (127.0.0.1) | панель 3x-ui |
| 2096/tcp | **нет** (127.0.0.1) | сервер подписок 3x-ui |
| 62789, 11111 | **нет** (127.0.0.1) | API и метрики Xray |
| 127.0.2.1:53 | **нет** | dnscrypt-proxy |
| 2019/tcp | **нет** (localhost) | API Caddy |
