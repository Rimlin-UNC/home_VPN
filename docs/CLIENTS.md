# Клиентские приложения

## Главное правило (октябрь 2026)

Сервер работает на **Xray-core 26.10.10**. Начиная с Xray **26.9.8** REALITY принимает только
ClientHello с ключом **X25519MLKEM768**, а ссылки используют отпечаток **firefox** (единственный,
который проходит и фильтр ТСПУ, и это требование). Поэтому нужен клиент на **Xray-core ≥ 26.3.23**
(в этой версии uTLS-отпечаток Firefox получил MLKEM).

| Платформа | Рекомендуется | Профиль |
|---|---|---|
| Android | **v2rayNG** (≥ 2.3), **Happ** | SN-XHTTP |
| iPhone / iPad | **Happ**, **Streisand**, **V2Box** — обновлённые, с Xray-core ≥ 26.3.23 | SN-TCP-iOS (если нет XHTTP) или SN-XHTTP |
| Windows | **v2rayN** (≥ 7.25, ядро Xray), **Happ Desktop** | SN-XHTTP |
| macOS | **Happ Desktop**, **V2Box**, v2rayN | SN-XHTTP |
| Linux | v2rayN или Xray-core из консоли | SN-XHTTP |

Проверить версию ядра: в настройках приложения («О программе», «Core version»).

### Не подойдут

| Приложения | Почему |
|---|---|
| NekoBox, Nekoray / Throne, Hiddify, Karing, sing-box (SFA/SFI/SFM) | ядро sing-box: нет X25519MLKEM768 в REALITY и нет XHTTP. Можно использовать **только профиль Hysteria2** |
| Clash Meta / Mihomo (FlClash, Clash Verge) | REALITY с MLKEM только с отпечатком chrome, а ТСПУ режет chrome |
| Старые версии v2rayNG/v2rayN/Streisand/V2Box | ядро старше 26.3.23 — отпечаток firefox без MLKEM, сервер его отвергнет |

## Подключение за 1 минуту

**Подписка (рекомендуется).** Профили обновляются сами (каждые 12 ч), при смене SNI или
переезде сервера ничего делать не нужно.

1. Получите от администратора QR-код подписки (`qr-subscription.png`) или ссылку
   `https://vpn.shprv.ru:ПОРТ/…/…`.
2. В приложении:
   - **v2rayNG**: ☰ → «Группа подписки» → «+» → вставить ссылку → ✓; затем ⋮ → «Обновить подписку».
   - **v2rayN**: «Подписки» → «Настройки подписок» → «Добавить» → URL → «Обновить подписки».
   - **Happ**: «+» → «Добавить из буфера» или «Сканировать QR».
   - **Streisand / V2Box**: «+» → «Добавить подписку» / «Импорт из буфера».
3. Выберите профиль **SN-XHTTP** (на iPhone — **SN-TCP-iOS**, если XHTTP не поддерживается) и
   подключитесь.

**Отдельные ссылки** (`vless://…`, `hysteria2://…`) из `links.txt` тоже можно импортировать,
но они не обновляются автоматически.

## Какой профиль выбрать

1. **SN-XHTTP** — основной (443/tcp, выглядит как HTTPS к `max.ru`).
2. **SN-TCP-iOS** — если не работает XHTTP или клиент его не поддерживает (8443/tcp).
3. **SN-HY2** — если оператор режет или замедляет TCP (443/udp). Не работает там, где режут UDP.

Если не работает ничего, а `sudo stealthnode doctor --e2e` на сервере показывает `OK`, вероятно,
у оператора включён режим «белых списков» (бывает на мобильном интернете в отдельных регионах).
Через один зарубежный сервер его не обойти — нужен российский relay (следующая фаза проекта).

## Hysteria2 и сертификат

Обычно Hysteria2 использует сертификат Let's Encrypt домена — подходит любому клиенту.
Пока сертификат не получен (DNS не настроен), сервер временно использует self-signed
сертификат, а в ссылке передаётся его отпечаток `pinSHA256`:

- Xray-клиенты (v2rayNG, v2rayN, Happ) проверяют отпечаток и подключаются;
- официальное приложение Hysteria2 дополнительно требует доверенный CA — вручную добавьте
  `insecure=1` к ссылке **вместе с** `pinSHA256` (отпечаток всё равно проверяется, MITM невозможен).

После появления Let's Encrypt сервер переключится сам; обновите подписку.

## Советы для родственников

- Включайте VPN только когда нужно, либо настройте раздельное туннелирование («Маршрутизация» →
  российские сайты напрямую) — экономит трафик и ускоряет банки/Госуслуги.
- Лимит — общий на все профили; при исчерпании доступ отключится до 1-го числа (автосброс)
  или до решения администратора.
- Лимит одновременных устройств — обычно 2 (телефон + планшет/ПК).
