# 🛡️ StealthNode — персональный VPN-сервер (Single-Server Edition)

Автоматическое развёртывание персонального VPN-сервера с веб-панелью администратора
на **одном VPS**, устойчивого к DPI-фильтрации (ТСПУ, 2026+). На том же сервере может
работать **торговый бот OKX** в изолированном контейнере.

## Состав стека

| Компонент | Роль |
|---|---|
| **AmneziaWG 3.1** (userspace, сборка из исходников) | Основной туннель. Обфускация Jc/Jmin/Jmax/S1–S4/H1–H4, случайный UDP-порт |
| **Xray-core 26.7.28** (VLESS + REALITY) | Резервный туннель на 443/tcp, маскировка под реальный сайт |
| **dnscrypt-proxy 2.1.18** | Шифрованный DNS; перехват всех DNS-запросов клиентов через DNAT |
| **FastAPI + WebSocket** | Бэкенд панели: JWT + Argon2id, real-time статистика |
| **SPA-панель** (vanilla JS, тёмная тема) | Дашборд, устройства, гости, бот, аудит — без сборщиков и CDN (строгая CSP) |
| **Caddy** | HTTPS (Let's Encrypt или internal CA), панель скрыта за секретным URL |
| **Торговый бот OKX** (Python + ccxt) | Изолированный контейнер, режим симуляции по умолчанию |
| **nftables + tc/ifb** | Квоты трафика и лимиты скорости гостей |

> **Примечание архитектора:** вместо SvelteKit панель реализована лёгким SPA
> без шага сборки (Node.js на VPS с 2 ГБ RAM — лишняя нагрузка и поверхность
> уязвимостей). Функциональность та же: WebSocket, real-time графики, тёмная тема,
> мобильная адаптивность. ТЗ допускает такие решения (раздел 0).

## Установка (одна команда)

```bash
curl -fsSL https://raw.githubusercontent.com/Rimlin-UNC/home_VPN/main/stealthnode/install.sh | sudo bash
```

Или из клонированного репозитория:

```bash
git clone https://github.com/Rimlin-UNC/home_VPN.git
cd home_VPN
sudo ./stealthnode/install.sh
```

Скрипт спросит:
1. **Пароль администратора** (мин. 16 символов, хранится как Argon2id-хеш);
2. **Домен маскировки REALITY** (не google/microsoft; рекомендуется популярный локальный ресурс с TLS 1.3 + HTTP/2);
3. **Домен панели** (опционально — для настоящего сертификата Let's Encrypt);
4. **API-ключи OKX** (опционально; без них бот работает в симуляции).

В конце установки на экране появятся:
- **URL панели** вида `https://IP:порт/p-x9f2k7/` (путь случайный — панель невидимa для сканеров);
- **QR-код конфига владельца** — отсканируйте его в приложении **AmneziaVPN**.

Все данные также сохраняются в `/root/stealthnode-credentials.txt` (права 600).

## Гостевые аккаунты (до 5)

Панель → «Гости». Поддерживаются:
- **Лимиты трафика**: день/неделя/месяц/общий (учёт по кумулятивным счётчикам + nftables);
- **Лимит скорости**: ↓/↑ в Мбит/с (tc + ifb, классы hfsc);
- **Временное окно** доступа (например 08:00–23:00), в т.ч. через полночь;
- **Срок действия** с автодеактивацией;
- **QoS-приоритет** (низкий/средний/высокий — доля гарантированной полосы в hfsc);
- **Экспорт журнала трафика в CSV**.

Проверка лимитов — каждые 5 минут; при исчерпании пир мгновенно удаляется
из `awg0` (разрыв соединения) и автоматически восстанавливается в новом периоде.

## Торговый бот OKX

- Изолирован в отдельном контейнере и **отдельной docker-сети** — у него нет доступа
  к VPN-стеку; лимиты ресурсов: `cpus: 0.5, memory: 512M`;
- По умолчанию **DRY_RUN (симуляция)**: реальные котировки OKX, виртуальный баланс
  10 000 USDT — можно оценить стратегию без риска;
- Для реальной торговли: введите ключи (Trade **без вывода средств**, привязка к IP VPS)
  и установите `OKX_DRY_RUN=false`;
- Защитный лимит `OKX_MAX_ORDER_USDT` ограничивает размер одного ордера;
- Панель: статус, PnL (день/всего), число сделок, позиции, логи (100 строк),
  редактор `bot.env` с маскировкой секретов.

## Управление после установки

```bash
cd /opt/stealthnode        # каталог установки (по умолчанию)
docker compose ps          # состояние контейнеров
docker compose logs -f     # логи всех сервисов
sudo ./setup.sh            # смена пароля/домена, итоговая информация
```

Смена пароля администратора вручную:

```bash
docker compose exec backend python -m app.utils.setpassword 'НовыйПароль12345678'
```
