# 🛡️ StealthNode — персональный VPN-сервер (редакция под ТСПУ-2026)

Автоматическое развёртывание персонального VPN-сервера с веб-панелью администратора
на **одном VPS**. Стек подобран по состоянию на 2026 год под российский DPI/ТСПУ —
без протоколов, которые РКН уже научился блокировать.

## Почему такой стек (исследование, сентябрь 2026)

| Протокол | Статус в РФ | Решение |
|---|---|---|
| AmneziaWG / WireGuard / OpenVPN | ❌ Детектируются и блокируются ТСПУ (AWG «не работает давно») | **Убраны полностью** |
| VLESS + TCP + REALITY (Vision) | ⚠️ С мая 2026 дефолтный профиль детектируется ML-классификатором ТСПУ по форме трафика у части провайдеров; у большинства продолжает работать | **Основной профиль** (порт 443) |
| VLESS + gRPC + REALITY | ✅ Работает (рекомендованная замена после детекта vision) | **Резерв №1** на случайном порту |
| VLESS + XHTTP + REALITY | ✅ Работает, современный транспорт 2026 | **Резерв №2** на случайном порту |
| Hysteria2 + Salamander | ✅ Работает и быстр на сетях с потерями; но ~15% провайдеров троттлят UDP, ~5% режут полностью | **Резерв** (не основа из-за UDP) |

Каждое устройство получает **три ссылки Xray сразу** + ссылку HY2 у владельца:
клиент ставит все и переключается автоматически (failover в клиентских приложениях).

## Готовые компоненты (не изобретаем велосипед)

- **Xray-core** — официальные релизные бинарники (закреплён v26.7.28: с v26.9.8
  REALITY требует постквантовый ML-KEM, ломая старые клиенты);
- **Hysteria** — официальные релизы apernet (закреплён v2.12.3);
- **dnscrypt-proxy** — официальные релизы (2.1.18, PQDNSCrypt);
- **Caddy** — официальный образ (HTTPS + сокрытие панели);
- Собственное ценное добавление — установщик одной командой, веб-панель
  (устройства/QR, гости с квотами, метрики по WebSocket) и изолированный бот OKX.

## Требования к VPS

| Параметр | Значение |
|---|---|
| ОС | **Ubuntu 24.04 LTS** |
| RAM | 2 ГБ (минимум 1 ГБ) |
| CPU | 1–2 vCPU |
| Диск | ≥ 20 ГБ |
| Бюджет | до 600 ₽/мес, оплата картой МИР |

### Рекомендуемые хостинги (оплата картой МИР): **VDSina.com** (Нидерланды, ~600 ₽) — основной выбор; IHC.ru (550 ₽), HOSTORA.RU (200 ₽), HostVDS (164 ₽), Hostkey (560 ₽). Для VPN важен **зарубежный IP**.

## Установка (одна команда / одна ссылка)

```bash
curl -fsSL https://raw.githubusercontent.com/Rimlin-UNC/home_VPN/main/stealthnode/install.sh | sudo bash
```

Скрипт спросит: пароль панели (≥16), домен маскировки (по умолчанию `max.ru`),
домен панели (опционально), ключи OKX (опционально). По завершении выводит
URL панели и **QR основной ссылки владельца**.

Всё также сохраняется в `/root/stealthnode-credentials.txt` (права 600).

## Подключение устройств

Панель → «Устройства» → «Ссылки/QR». Приложения-клиенты (все понимают vless:// и hy2://):

| Платформа | Клиенты |
|---|---|
| Android | v2rayNG, NekoBox, Hiddify, Happ |
| iOS | Streisand, Shadowrocket, FoXray, Happ |
| Windows | v2RayN, Nekoray, Clash Verge, Hiddify |
| macOS | V2Box, FoXray, Clash Verge |
| Роутеры | OpenWrt (passwall/homeproxy), Keenetic (через opkg xray) |

В модалке устройства — QR основного профиля и три ссылки текстом;
в «Настройках» у владельца дополнительно ссылка **Hysteria2**.

## Гостевые аккаунты (до 5)

Панель → «Гости»:
- **Лимиты трафика**: день/неделя/месяц/общий — учёт по per-user статистике Xray
  (StatsService), склейка счётчиков переживает перезапуски;
- **Временное окно** доступа (например 08:00–23:00, поддержка «через полночь»);
- **Срок действия** с автодеактивацией;
- **Экспорт журнала трафика в CSV**.

Проверка — каждые 5 минут; при срабатывании клиент удаляется из всех транспортов
(мгновенный разрыв) и возвращается в новом периоде автоматически.

> Пер-пользовательское ограничение **скорости** в прокси-стеке технически
> недостижимо (трафик клиентов неразличим внутри TLS) — вместо него: трафиковые
> квоты, окна и сроки. См. docs/SECURITY.md.

## Торговый бот OKX

- Отдельный контейнер и **отдельная docker-сеть**, лимиты `cpus: 0.5, memory: 512M`;
- По умолчанию **симуляция** (живые котировки, виртуальный баланс 10 000 USDT);
- Боевая торговля: ключи Trade **без вывода**, привязка к IP, `OKX_DRY_RUN=false`;
- Панель: статус, PnL, сделки, позиции, логи (100 строк), редактор `bot.env`
  с маскировкой секретов.

## Управление после установки

```bash
cd /opt/stealthnode
docker compose ps          # состояние контейнеров
docker compose logs -f     # логи
sudo ./setup.sh            # пароль, домен маскировки, ссылки владельца + QR
```
