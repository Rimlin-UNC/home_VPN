## [2.0.0] — 2026-10-14

Полная переработка по ТЗ v2 ([docs/TZ-v2.md](docs/TZ-v2.md)); разбор ТЗ и принятые решения —
[docs/TZ-REVIEW.md](docs/TZ-REVIEW.md).

### Добавлено
- Установщик `stealthnode/install.sh` для чистой Ubuntu 24.04: предпроверки (ОС, ресурсы, порты,
  внешний IP, A-запись домена, IPv6), журнал `/var/log/stealthnode/install-*.log`, перехват ошибок
  с указанием шага и строки, безопасный повторный запуск.
- Протоколы (Xray 26.10.10 в составе 3X-UI v3.10.0):
  - VLESS + XHTTP (`mode=stream-one`) + REALITY на 443/tcp, без flow, `fp=firefox`;
  - VLESS + TCP + REALITY + Vision на 8443/tcp для iOS (те же ключи и shortId);
  - Hysteria2 + Salamander на 443/udp внутри Xray (общие лимиты и подписка).
- Панель 3X-UI (закреплённая версия, проверка SHA256 установщика): только на 127.0.0.1,
  наружу — через Caddy по HTTPS на отдельном порту; случайные порт, путь, логин и пароль; API-токен.
- Пользователи: одна запись на человека для всех трёх протоколов — общая квота трафика
  (например, 50 ГБ/мес с ежемесячным сбросом), лимит одновременных IP, одна подписка.
- CLI `stealthnode`: `doctor [--e2e] [--speed]`, `user add|del|list|show|limit|reset`, `links`,
  `backup`/`restore`, `cert-sync`, `sni-check`/`sni-set`, `export-config`, `info`, `token-rotate`.
- `stealthnode doctor --e2e`: проверки раздела 8 ТЗ в исправленном виде и реальное подключение
  по каждому профилю клиентом Xray с самого сервера (+ замер скорости).
- Сертификат Hysteria2: Let's Encrypt от Caddy (автосинхронизация по таймеру), до его получения —
  self-signed + `pinSHA256` (без `insecure=1`).
- dnscrypt-proxy (127.0.2.1) как DNS для Xray, резерв — DoH 1.1.1.1.
- Защита: UFW (только нужные порты), fail2ban (SSH 3/10 мин → 24 ч; перебор пароля панели;
  recidive; лимит IP 3x-ui), BBR и sysctl, swap на малых VPS, автообновления безопасности,
  опционально SSH только по ключам и нестандартный порт с безопасным переходом.
- Ежедневные резервные копии (14 шт.) и перенос на новый VPS (`--restore`) без смены ссылок.
- Встроенный Telegram-бот 3x-ui на русском (`--tg-token`, `--tg-chat`).
- Документация: установка, клиенты, обслуживание, безопасность, тестирование, архитектура.
- Тесты: pytest (вкл. векторы RFC 7748 для X25519 и провижининг против фейкового API 3x-ui),
  bats, локальный E2E протоколов на настоящих Xray 26.10.10 и Hysteria 2.13,
  CI GitHub Actions с полной установкой на Ubuntu 24.04 и проверкой контракта с 3x-ui.

### Исправлено до выпуска (найдено тестами и CI на чистой Ubuntu 24.04)
- 3x-ui v3 отдаёт шаблон Xray (`POST /panel/api/xray/`) JSON-строкой внутри `obj` — разбор исправлен.
- `caddy validate` от root создавал `/var/log/caddy/caddy.log` с владельцем root, и служба Caddy
  не запускалась (`permission denied`) — проверка выполняется от пользователя `caddy`.
- dnscrypt-proxy из Ubuntu 24.04 (2.0.45) не понимал ключи новых версий — конфиг совместим с 2.0.x,
  проверяется `dnscrypt-proxy -check`, при отказе остаётся конфиг пакета.
- `sshd -t`/`sshd -T` падали без `/run/sshd` (в Ubuntu 24.04 с `ssh.socket` каталог появляется
  только после первого запуска sshd) — каталог создаётся перед проверкой.
- Смена порта SSH в Ubuntu 24.04: drop-in `ListenStream=ПОРТ` при `BindIPv6Only=ipv6-only` от генератора
  оставлял SSH только на IPv6 (потеря доступа на IPv4-сервере). Теперь порты применяет штатный генератор,
  каждый порт проверяется IPv4-подключением, при неудаче изменения автоматически откатываются.
- Гонка после восстановления из бэкапа: проверка процесса Xray выполнялась раньше, чем 3x-ui
  его перезапускала — `restore` ждёт панель и ядро.
- Добавление/удаление пользователя и повторная установка больше не перезапускают ядро Xray
  (не рвут соединения): 3x-ui применяет изменения клиентов на лету.
- Официальный клиент Hysteria2 требует доверенный CA даже с `pinSHA256` — учтено в документации,
  основной режим — сертификат Let's Encrypt.

### Изменено
- Вместо собственной панели (FastAPI) — 3X-UI v3; вместо Docker — системные службы.
- Торговый бот OKX больше не ставится на VPN-сервер.

### Удалено
- Реализация v1 перенесена в [`legacy/v1/`](legacy/README.md) (история сохранена).

### Безопасность
- Сырые порты панели и подписки не открываются наружу; секреты — в файлах с правами 600.
- Отпечаток `firefox`: единственный, проходящий и фильтр ТСПУ (июнь 2026), и требование
  X25519MLKEM768 в REALITY Xray ≥ 26.9.8 (проверено тестом: `fp=ios` отвергается).
